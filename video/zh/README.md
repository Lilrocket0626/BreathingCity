# 呼吸城市 中文讲解视频

播放 [BreathingCity_3min_Explainer_zh-CN.mp4](BreathingCity_3min_Explainer_zh-CN.mp4)。视频时长 3 分钟，1920×1080、30 帧/秒，包含普通话合成旁白、烧录中文字幕和中文讲解卡片。代码摘录保留英文原文及真实行号。

运行片段来自原版视频中实际 Processing 程序导出的连续帧，界面原貌保留。外层中文标题明确标注“自动演示 / 合成音量输入”。这段片段演示程序如何响应强弱变化，不替代真人麦克风测试；实际麦克风记录见 [测试报告](../../docs/runtime-test-report.md)。

旁白使用 macOS **Tingting** 普通话合成语音，并非学生本人录音。文案、字幕和讲解制作使用了 AI 协助。若课程要求本人讲解，请使用配套中文稿练习后自行录音。

## 配套文件

- `captions.zh-CN.srt`：UTF-8 中文字幕，可导入播放器或剪辑软件。
- `captions.zh-CN.ass`：视频中使用的字幕样式及时间轴。
- `narration.txt`：八段完整中文讲稿。
- `narration.wav`：三分钟普通话合成音轨。
- `audio-timing.json`：各章节原始语音长度及语速调整值。
- `assets/source-excerpts.json`：讲解中展示的源码、文件和行号。
- `video-manifest.json`：视频校验值、来源及版本记录。
- `video-validation.json`：最终文件的时长、解码、字体及源码核验记录。

字幕以逐句合成语音的实测长度对齐，各章节的声音与字幕使用相同的时间缩放。没有用中文字数猜测每句的起止时间。

## 重新生成

从项目根目录运行 `python3 tools/build_video_zh.py`。首次生成需要 Python 3、Pillow、FFmpeg/FFprobe，以及 macOS 的 Tingting 语音与黑体、Menlo 字体。这些只是视频制作依赖，不影响 Processing 项目运行。保留的语音 WAV 可用于之后的重复构建。脚本读取 `video/assets/runtime-demo.mp4`，不会采集麦克风或录制桌面。

英文版保留在 [video 主目录](../README.md)。中文字幕和中文卡片不改变程序源码，也不产生新的真人测试记录。
