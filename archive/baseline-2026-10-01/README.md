# Breathing City

*Breathing City* is an interactive visual artwork built in Processing. It converts live microphone amplitude into a responsive, Sydney-inspired night city. A gentle breath creates subtle light and movement; a stronger breath warms the sky, illuminates windows, accelerates particles, expands harbour waves, and releases a visible breath ring.

This repository was created for 52685 Creative Coding, Assessment 2.

## Core interaction

The project uses the following data flow:

`microphone → amplitude → room-noise calibration → mapping → smoothing → visual intensity`

The processed intensity value controls:

- sky and window colour;
- moon size and glow;
- harbour-wave height;
- particle creation, motion, colour, and size; and
- the creation of expanding breath rings.

## Requirements

- Processing 4 in Java mode
- Processing Sound library
- A computer with a microphone
- Headphones are recommended to prevent audio feedback

No downloaded image, audio, or font assets are required. All visuals are generated by the code.

## Installation and running instructions

1. Download and install Processing 4 from <https://processing.org/download>.
2. Open Processing.
3. Select **Sketch → Import Library → Manage Libraries**.
4. Search for **Sound** and install the official Processing Sound library.
5. Open `BreathingCity/BreathingCity.pde`.
6. Select Java mode and press **Run**.
7. Give Processing microphone permission if the operating system asks.
8. Remain quiet during the three-second calibration.
9. Breathe or blow gently towards the microphone.

## Controls

| Key | Action |
|---|---|
| `M` | Toggle between microphone and mouse simulation mode |
| `R` | Recalibrate the room-noise floor |
| `D` | Show or hide the live data panel |
| `H` | Show or hide the control guide |
| `S` | Save a PNG screenshot |

In simulation mode, move the mouse horizontally. The left edge represents zero intensity and the right edge represents maximum intensity. This fallback makes the interaction demonstrable when a computer blocks microphone access.

## Code structure

The sketch is intentionally kept in one `.pde` file so it can be opened and assessed easily. The code is divided into small functions and classes:

| Component | Responsibility |
|---|---|
| `BreathInput` | Captures audio, estimates room noise, maps the signal, and smooths the result |
| `Building` | Stores and draws one procedurally generated building and its windows |
| `Star` | Stores the position and size of a stable star |
| `BreathParticle` | Stores one particle's position, velocity, lifetime, and appearance |
| `BreathWave` | Represents an expanding ellipse triggered by a breath event |
| `LevelGraph` | Stores recent intensity samples in a circular array and draws the live graph |
| `triggerBreathWave()` | Detects a threshold crossing and applies a cooldown |
| `emitParticles()` | Adds a breath-dependent number of particles while enforcing a maximum |

## Troubleshooting

### The Sound library cannot be found

Install **Sound** through Processing's Contribution Manager, restart Processing, and run the sketch again.

### The microphone does not respond

- Check the operating system's microphone privacy settings.
- Confirm that Processing is allowed to access the microphone.
- Press `R` and stay quiet during recalibration.
- Move closer to the microphone.
- Press `M` to demonstrate the visual system in simulation mode.

### The animation responds to background noise

Move to a quieter space and press `R`. The program will take a new three-second sample and place its noise floor above the average measured room level.
