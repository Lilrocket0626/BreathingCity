# Runtime Evidence

Place genuine screenshots and short recordings from the Processing runtime tests in this folder. Use descriptive filenames such as:

- `01-calibration.png`
- `02-calm-state.png`
- `03-soft-breath.png`
- `04-strong-breath.png`
- `05-simulation-mode.png`
- `peer-test-01.mp4`

Do not add staged or generated images as runtime evidence.
