# Declaration of generative AI use

I used ChatGPT and Codex as supporting tools during the development of *Breathing City*. I used these tools to brainstorm and clarify the project direction, explain Processing and Sound library concepts, generate and revise sections of code and code comments, suggest testing methods, locate official technical sources, and draft and edit written materials. The tools did not make final submission decisions, record my presentation, or submit the assessment. I reviewed the generated suggestions, selected appropriate changes, checked technical information against official Processing documentation, and take responsibility for understanding and explaining the final prototype.

The main advantage of AI was that it provided quick explanations and helped identify technical issues involving noise calibration, thresholds, smoothing and code organisation. This supported my understanding of how microphone amplitude is transformed into visual changes. The main disadvantage was that AI could produce confident explanations that went beyond the available evidence. For example, measuring microphone loudness is not the same as recognising human breathing. I therefore retained test evidence, checked technical claims and stated the project's limitations.

Overall, AI assisted the development process, but I remained responsible for reviewing the work, understanding the core logic, making final choices and narrating the explainer video myself.

This declaration matches Appendix D of the written critical reflection. The accompanying [AI activity log](ai-prompt-log.md) and submitted conversation screenshots provide more detail about the prompts and outputs.
