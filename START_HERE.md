# Start here

**The final runnable file is [`BreathingCity/BreathingCity.pde`](BreathingCity/BreathingCity.pde).**

1. Read [README](README.md) for the tested versions, installation and controls.
2. Install **Processing 4.5.7** and official **Sound 2.4.0**, then open the final file in Java mode.
3. Keep all five files in `BreathingCity/` together. The `archive/` folder is the unmodified earlier version, not the final submission.
4. Read the [actual runtime report](docs/runtime-test-report.md) for measured evidence and test limits.
5. Use the [Chinese study guide](docs/study-guide-zh.md) and [presentation materials](presentation/README.md) for the code explanation.
6. See [archive export notes](archive/EXPORT-NOTES.md) for how the historical baseline is preserved and packaged.

Do not redistribute local Processing installations or assume all content in the preserved baseline is verified. Runtime screenshots and source differences are in `docs/evidence/`.
